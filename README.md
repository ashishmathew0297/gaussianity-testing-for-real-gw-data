# Limits and capabilities of time-domain gaussianity testing in real gravitational-wave detector data

The field of Gravitational-wave (GW) data analysis has exploded in recent years, and is set to transform our understanding of astrophysics and cosmology as the LIGO-Virgo-KAGRA collaboration upgrades its current ground-based detectors. Nonetheless, As we move from noise-dominated datasets to signal-dominated ones, there is an increased need for stress-testing future data analysis algorithms. There is growing interest in constructing controlled datasets, known as mock data challenges (MDCs), as testbeds for the novel technologies being explored. To fully capture the complexity of real detector data, we need to include realistic signals of non-Gaussian transient burst noise, also known as glitches, by separating them from non-structured Gaussian-like detector noise. This work systematically investigates the effectiveness and limitations of statistical hypothesis testing in the time-amplitude domain using statistical tests of Gaussianity.
